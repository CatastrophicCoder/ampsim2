The merged preamp alone exceeds the per-sample budget (1.0–1.4× with static knobs, 3.3× while all knobs
move). Before B5 / B6 are added this needs the M6 work: chord Newton and lookup tables for the per-sample
cost, and for the knob updates a cheaper update path (larger interval, partial recomputation, or the
worker thread of WDF_DESIGN §5.4).

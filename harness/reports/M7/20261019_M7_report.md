# M7 report — CPU optimisation

Status: for owner review (2026-10-19). Scope (owner, 2026-10-19): lower the plugin's CPU at its defaults, above all at high
Master, toward a 20 % working budget of one core, without loosening a tolerance. Details: `docs/PROGRESS.md` (M7), DECISIONS
D-065 … D-070.

The engine changes (D-065 – D-068, D-070) leave the verified results unchanged (plugin model check at Full identical to
M6). The default Power Amp Rate is now Half (owner decision, D-069): it meets the budget at default knobs and is about 22 – 25 %
at high Master, with HOT at −18.9 dB against the −20 dB target (deviation accepted by the owner) and latency 49 → 58
samples at 48 kHz.

## Changes

| Decision | Change | Effect |
|---|---|---|
| D-065 | Newton keeps its LU factors; Jacobian predictor from them; preamp J4 Thevenin resistance from them | iterations per solve at NAM 3.46 → 2.34 (power amp), 1.41 → 0.66 (preamp); plugin NAM 42.7 → 33.4 % |
| D-066 | fast Wright omega (series / table start + one step, ≤ 1e-14 of the reference), E1^ex via exp / log, no outputs for the preamp's trial solve | engine NAM −8 % |
| D-067 | preamp's second J4 solve → linear load correction when ≤ 10 mV (−115 / −126 dB vs the re-solve) | default knobs −11 % |
| D-068 | linear J4 port out of both Newton systems (9 → 8, 11 → 10 ports) | −2 … −3 % |
| D-069 | plugin default Power Amp Rate Half (Full selectable) | −31 % at NAM; HOT −18.9 dB |
| D-070 | power-amp maxIter 48 (was 32) | 3 Half automation failures after D-068 removed |

Tried, not adopted: relaxed step halving, EL34 step limits, chord iterations, float LU (no gain), half-steps off / 300 V
(−2 / −1.4 points, HOT and unseen margins smaller), trend guards on the predictor (8 – 18 % slower).
